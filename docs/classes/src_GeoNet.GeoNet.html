    Class GeoNet

    Main class for interacting with the GeoNet API and related utilities. Provides access to all GeoNet services through a unified interface.

    Remarks

    This class acts as a central interface for all GeoNet API services and related utilities, thus providing a simplified way to access earthquake, volcano and network data, among others, from GeoNet.

    Example

    import { GeoNet } from "geonet";
    const geonet = new GeoNet();

    // Get recent earthquakes
    const quakes = await geonet.getQuakes(...);

    See

    • https://api.geonet.org.nz GeoNet API Documentation.
    • IntensityService For intensity-related methods.
    • StrongService For strong motion-related methods.
    • NewsService For news-related methods.
    • QuakeService For quake-related methods.
    • VolcanoService For volcano-related methods.
    • NetworkService For network-related methods.
    • QuakeMapUtil For generating GeoNet quake map URLs.
